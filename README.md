# 🧾 Receipt Booth

Receipt Booth adalah aplikasi kiosk untuk mencetak struk/receipt aesthetic dengan foto di kertas thermal.

## 🚀 Features

- **Multi-package pricing** - 1-4 foto dengan harga berbeda
- **QRIS Payment** - Integrasi pembayaran QRIS
- **Camera capture** - Foto dengan countdown timer
- **Thermal printing** - Cetak receipt di kertas thermal
- **Admin panel** - Kelola branding, harga, dan frase
- **Export/Import config** - Backup & restore pengaturan

## 📦 Quick Start

1. Clone repository
2. Buka `index.html` di browser
3. Akses admin: Klik "⚙️ ADMIN" (password: `admin123`)
